2. При загрузке страницы (или сразу после) срабатывал **`loadSavedSession`** — восстановление прошлого ответа модели.
3. Он **перезаписывал превью** старым `image_url` из прошлой сессии (график доллара).
4. При **Отправить** уходил именно этот старый URL.

Сейчас в prefs всё ещё записан старый файл:
`7ca663b93d6a46fb8eebe503ab6050f0_Generated_Image_May_07_2026_-_2_30PM.jpg` — график доллара, не новый стиль.

## Что исправлено

1. **Сессия больше не трогает фото** — прикреплённое изображение берётся только из prefs / свежей загрузки.
2. **URL хранится явно** в `data-later-image-url`, не только в `preview.src`.
3. **Под превью показывается имя файла** — видно, что реально уйдёт в запрос.
4. **В лог пишется** `Фото прикреплено: …` и `→ фото в запросе: …` при отправке.
5. **Cache-buster** на превью — браузер не показывает старую картинку по тому же URL.

Готово. У **Result AS** теперь такой же режим редактирования, как у Result и Inbox.

**Что добавлено**

1. **Кнопка ✎ / ✓** в тулбаре Result AS (между бейджем и копированием).
2. **✎** — разблокирует textarea, можно править JSON вручную.
3. **✓** — сохраняет в prefs, обновляет проверку и **отправляет исправленный текст в SceneMap Agent** (поле «Result AS (MacroMap)» внизу).

**Как это работает**

- Пока редактируете (textarea разблокирована), SceneMap получает изменения **сразу** при вводе.
- После **✓** данные сохраняются и явно синхронизируются с SceneMap; при запуске SceneMap Agent уходит уже исправленная версия.
- Блок «Проверка Result AS» теперь валидирует **содержимое Result AS** (поля `text` в блоках), а не только автосборку из Result + Inbox — ручные правки тоже проверяются.

Обновите страницу и попробуйте: ✎ → правка → ✓ → в SceneMap Agent должен появиться обновлённый JSON.

### Как применяется шаблон
При выборе другого шаблона в карусели (клик по плитке) сразу:
1. Загружаются данные шаблона с сервера (Hero, Master, символы, промпты этапов)
2. Поля на странице обновляются
3. Проект сохраняется с новым `rewrite_template`

Можно переключать шаблоны подряд — каждый раз подтягиваются настройки выбранного. Поля **не блокируются** автоматически (в отличие от старой кнопки «Применить»).

При создании шаблона через **＋** или после удаления в редакторе список обновляется, и при смене выбранного шаблона настройки тоже подгружаются.

**Cursor**

Ищем логику проверки JSON для этапа Analysis — ответ выглядит как JSON, но парсер, скорее всего, падает на синтаксической ошибке.


Проверка Analysis не смотрит на «похоже на JSON» — она делает обычный `JSON.parse()` по тексту в поле **Result**. Если парсер падает, показывается **«Ожидание валидного JSON»**, даже когда структура на глаз правильная.

## В чём ошибка в вашем ответе

В блоке `donor_voice_signals`, второй элемент — **сломанная строка** (кавычки не сходятся):

```json
"location": "Серии одухотворённых личных отступлений с \"Это не твоя вина…\"',
```

Строка открыта двойной кавычкой `"`, а закрыта **одинарной** `'` — для JSON это невалидно. Из‑за одной такой строки **весь** объект не парсится, и проверка остаётся в ожидании.

Нужно так:

```json
"location": "Серии одухотворённых личных отступлений с \"Это не твоя вина…\"",
```

### 1. Галочка у User Promt (не скрывается / «не сохраняется»)

В `_rewrite_block_scripts.html` функция `applyAnalysisUserPromptLockUI` **сразу выходила** для любого этапа, которого нет в длинном списке — там **не было `rewrite`**.  
Сохранение на сервер при этом могло проходить, но **readonly / скрытие блока и стиль кнопки не применялись**, поэтому визуально казалось, что «ничего не произошло».

**Исправление:** в список этапов для этой функции добавлен `rewrite` (то же в `rewrite_project.html` для старой страницы).

### 2. Кнопка «↻» (запуск агента)

В `_iter_stage_run_event_strings` для запуска стояла проверка: если этап **не** в фиксированном списке и пустой «исходный текст сверху» — ошибка *«Введите исходный текст в верхнем поле»*.  
Этап **`rewrite` в этот список не входил**, поэтому запуск срывался, даже при заполненном Inbox.

**Исправление:** в `app.py` в тот же список, что и для `author` / редакторов, добавлен **`rewrite`** (ему не нужен верхний source).

### 3. Скрывался ↻ у Voiceover / Title / Splitter без прогона Rewrite

В `syncStageRunButtons` клиент **требовал непустой Result у предыдущего этапа в пресете**. После Inbox идёт `rewrite` — пока Result Rewrite пустой, **следующие этапы считались заблокированными**, хотя по серверу Rewrite **опционален** (достаточно Inbox).

**Исправление:** для пресета `prewritten` при обходе предков **пропускаем проверку `rewrite`**, если смотрим не на саму карточку `rewrite` (логика как на бэкенде: можно идти дальше с одним Inbox).

## Как работает (UX)

1. На карточке исходного текста рядом с кнопкой «Перевести на русский» теперь стоят `System Promt: YES` и `✎` (фиолетовые).
2. Клик `✎` → модалка, видно текущий промт перевода. Можно редактировать.
3. Внизу модалки — цифровая клавиатура; набираешь `1 2 3 4` → запрос уходит → если совпало с `LOCKED_PROMPTS_PIN` в `.env`, текст сохраняется в `locked_prompts/translate_to_ru.txt` и используется в следующих запусках перевода.
4. Кнопка «Сбросить» возвращает в textarea то, что сейчас лежит на сервере (отменяет локальные правки, ничего не пишет).

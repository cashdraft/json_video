## Текущая архитектура (код)

### Единый проект
На `/` создаётся **один проект** с общим ID: ReWrite + Video на странице `job/<id>` (см. `templates/home.html`).

### ReWrite — этапы (`rewrite_pipeline.py`)

```
Inbox → Rewrite → Analysis → Architect → Block Writer
→ Retention / Hook / Flow / Persona / Voiceover / ElevenLabs editors
→ Title Strategist → Structure Splitter → Scene Writer → YouTube packaging
```

- Промпты в `rewrite_templates/`, блокировки в `locked_prompts.py`.
- Стриминг задач: `/rewrite/<id>/run/start`, events, cancel.
- OpenAI + опционально **Claude via Kie** (`rewrite_openai.py`, `claude_kie.py`).

### Video / JSON сцен
Формат сцены (как в самом начале):

- `scene_id`, `text` (для верстки/озвучки)
- `start.prompt` / `end.prompt` → картинки
- `video.prompt` → видео со start-кадра (если не null)

Генерация: **Kie** (`kie_client.py`), шаблоны референсов (`image_templates/`).

### Озвучка и тайминги
- **Eleven**: один запрос `with-timestamps` → MP3 + alignment → локально `.words.json`.
- Длинный текст: **чанки по предложениям** (после ~1500 символов — ~3–4 запроса).
- **Whisper**: отдельный прогон по MP3 (`whisper_words.py`).
- Для сцен надёжнее **Whisper**; у Eleven бывают схлопнутые `start_ms` и SSML-мусор (`<break>`, `[tone]`).
- В UI: проверки (хвост, нулевая длина, «Пауза более 30 с»), слова-исключения vs чистые слова.

### Монтаж
- **Remotion** в `/srv/json_video/remotion/` — `JobMontage`, вызов из бэкенда.
- `job_montage_prepare.py`, `job_scene_audio_align.py` — подготовка и выравнивание сцен с аудио.

### Ключевые модули
| Файл | Роль |
|------|------|
| `app.py` | ~9k строк, все роуты |
| `rewrite_pipeline.py` | Стадии, пресеты, compose prompts |
| `elevenlabs_client.py` | TTS + timestamps, chunking |
| `task_manager.py` | Фоновые задачи |
| `templates/rewrite_project.html` | UI ReWrite |
| `templates/job.html` | Video, TTS, Whisper, сцены |

Данные: `data/jobs/`, `data/rewrite_jobs/`, `data/job_audio/`.

## Важные решения из последних сессий (50)

- Длительность в UI — по **`end_ms` последнего слова**, не по длине файла.
- Whisper: статус с Cancel, ↻ крутится, Result не пропадает после F5.
- Eleven TTS при >1500 символов — принудительно несколько чанков по `.`.
- `animation_planner` в ReWrite **снят**; анимация планируется в другом месте пайплайна / job.

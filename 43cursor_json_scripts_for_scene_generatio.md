Да, это можно посчитать по CSS — отступ **сверху у самой карточки не меняется**, смещается содержимое **внутри** строки шапки.

### Что фиксировано (не меняется при свёртке)

У сворачиваемых этапов верхний padding карточки один и тот же:

```4111:4113:/srv/json_video/static/style.css
.scene-card.rewrite-stage-card.rewrite-stage-card--collapsible {
    padding-top: 0.55rem;
}
```

При `font-size: 16px` на корне это **≈ 8,8 px** от верхней рамки блока до начала `.scene-header` — и в развёрнутом, и в свёрнутом виде.

### Почему «Rewrite» и «?» визуально опускаются

При свёртке тела (`rewrite-stage-card--body-collapsed`) в одну строку с названием появляется блок **Result + ↻**:

```2186:2199:/srv/json_video/static/style.css
.rewrite-stage-card.rewrite-stage-card--collapsible.rewrite-stage-card--body-collapsed .rewrite-stage-card-compact-result {
    display: inline-flex;
    align-self: center;
}

.rewrite-stage-card.rewrite-stage-card--collapsible.rewrite-stage-card--body-collapsed .rewrite-stage-title-row {
    min-height: 24px;
    align-items: center;
}

.rewrite-stage-card.rewrite-stage-card--collapsible.rewrite-stage-card--body-collapsed .rewrite-stage-header-tools {
    min-height: 24px;
    align-items: center;
}
```

Высота **Result** и **↻** задана явно:

```4425:4439:/srv/json_video/static/style.css
.slot-badge {
    ...
    height: 24px;
    min-height: 24px;
}

.btn-regenerate {
    width: 24px;
    height: 24px;
```

**Развёрнутая карточка** (в шапке нет Result/↻, блок скрыт): высота строки заголовка ≈ высоте кружка «1» — **1,2 rem ≈ 19,2 px** (номер этапа).

**Свёрнутая карточка**: строка `.rewrite-stage-header-top` по сути становится **24 px** — подстраивается под бейдж Result и кнопку ↻; для `.rewrite-stage-title-row` и `.rewrite-stage-header-tools` включается **`min-height: 24px`**.

Прирост высоты строки шапки: **24 − 19,2 ≈ 4,8 px** (округлённо **~5 px**).

### На сколько увеличивается отступ до текста «Rewrite» и «?»

Верх строки шапки не опускается (`align-items: flex-start` на `.rewrite-stage-header-top`), но внутри более высокой строки элементы **центрируются** (`align-items: center` + `min-height: 24px`):

| Элемент | Развёрнуто (≈) | Свёрнуто (24 px, по центру) | Доп. сдвиг вниз |
|--------|----------------|-----------------------------|------------------|
| **Rewrite** (текст ~18 px в строке ~19 px) | ~0,6 px от верха строки | ~3 px от верха строки | **~2–3 px** |
| **?** (иконка 16 px) | у верха строки (~16 px) | (24−16)/2 = **4 px** от верха строки | **~4 px** |

**Итого от верхней рамки карточки до «Rewrite»** (грубо):

- развёрнуто: **0,55 rem + ~0,6 px ≈ 9–10 px**
- свёрнуто: **0,55 rem + ~3 px ≈ 12 px**

**Прирост визуального отступа до надписи «Rewrite» — порядка 2,5–3 px** (не 5 px: 5 px — это рост высоты всей строки, а не padding карточки).

До **«?»** — примерно **+4 px** из‑за `min-height: 24px` у `.rewrite-stage-header-tools`.

### Краткий вывод

- **Padding карточки сверху не растёт** — всегда **0,55 rem (~8,8 px)**.
- Строка шапки становится выше примерно на **5 px** из‑за блока **Result + ↻** (24 px).
- «Rewrite» и «?» съезжают вниз ещё на **~2–3 px** и **~4 px** соответственно из‑за вертикального центрирования в этой 24 px строке.

В коде это как раз описано в комментарии к `align-items: flex-start` у `.rewrite-stage-header-top` (строки 2060–2062 в `style.css`).

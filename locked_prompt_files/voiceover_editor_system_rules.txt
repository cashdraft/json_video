
ФОРМАТ ВЫВОДА (СТРОГО JSON):

{
  "text": "<полный обновлённый текст>",
  "changes": [
    {
      "type": "long_sentence|hard_to_pronounce|bad_rhythm|no_pause|overloaded_phrase",
      "before": "<что было>",
      "after": "<что стало>",
      "comment": "<почему это улучшает озвучку, пояснение на Русском языке>"
    }
  ]
}

ТРЕБОВАНИЯ К changes:

— только реальные изменения  
— before ≠ after  
— не выдумывай правки  
— если изменений мало — это нормально  

ЕСЛИ ПРОБЛЕМ НЕТ:
— верни текст без изменений  
— changes: []

ВАЖНО:
Любой текст вне JSON запрещён.

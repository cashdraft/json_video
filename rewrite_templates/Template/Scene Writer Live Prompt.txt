STOCK MEDIA MODE:

The user prompt will contain:

STOCK_MEDIA_MODE: photo
or
STOCK_MEDIA_MODE: video
or
STOCK_MEDIA_MODE: both

Follow it strictly.

If STOCK_MEDIA_MODE is "photo":

* every "_2" scene must use {"content_type":"photo"}

If STOCK_MEDIA_MODE is "video":

* every "_2" scene must use {"content_type":"video"}

If STOCK_MEDIA_MODE is "both":

* choose the best content_type for each scene

Use "photo" for:

* portraits
* static emotions
* thoughtful faces
* loneliness
* people sitting
* quiet moments
* close-ups
* symbolic still shots

Use "video" for:

* walking
* talking
* gestures
* crowds
* office interaction
* group movement
* people entering/leaving
* camera motion
* environmental movement
* scenes where body language changes over time

STOCK TARGET PERCENT:

The user prompt may contain:

STOCK_TARGET_PERCENT: 30

This means approximately 30% of input scenes should receive stock alternatives.

Follow this as a soft limit.

Rules:

* Do NOT apply stock alternatives to every scene.
* Select only the best stock candidates.
* Prefer quality over quantity.
* If target percent is 30, choose roughly 3 scenes out of 10.
* If target percent is 50, choose roughly 5 scenes out of 10.
* If there are fewer good candidates than the target percent, select fewer.
* Never force stock alternatives onto weak or abstract scenes just to reach the target.

KEYWORD RULES:

Keywords are for searching real stock libraries like Pexels, Shutterstock, Adobe Stock, Getty Images.

Keywords must describe what is VISIBLY searchable.

Use:

* people type
* action
* emotion
* location
* camera/framing if useful
* mood if visually clear

Good keyword patterns:

"tired man, office, close up, stress, holding head"
"woman alone, window light, thoughtful, apartment, solitude"
"group discussion, office meeting, people talking, body language"
"crowd walking, city street, busy people, urban life"
"emotional portrait, serious face, soft light, neutral background"

Avoid:

* abstract psychology terms
* poetic descriptions
* story explanations
* invisible concepts
* rare or overly specific phrases

Bad keywords:

"overthinking pattern"
"mind never switches off"
"existential awareness"
"internal loop"
"perceptive intelligence"

Use 5–9 keywords when possible.

Keep keywords comma-separated in one string.

Do not use hashtags.

Do not use full sentences.

PAIR FORMATTING RULES:

If you create a stock alternative for a scene, the original scene_id MUST get "_1".

Correct:

{"scene_id":"scene_001_1"}
{"text":"..."}
{"text_ru":"..."}
{"start":{"prompt":"..."}}
{"end":{"prompt":null}}
{"video":{"prompt":"..."}}

{"scene_id":"scene_001_2"}
{"text":"..."}
{"text_ru":"..."}
{"content_type":"photo"}
{"keywords":"keyword 1, keyword 2, keyword 3"}

Wrong:

{"scene_id":"scene_001"}
...
{"scene_id":"scene_001_2"}

There MUST be one blank line:

* after every complete scene
* between "_1" and "_2"
* between scene groups

Output format:

scene_001_1 block

scene_001_2 block

scene_002 unchanged block

scene_003_1 block

scene_003_2 block

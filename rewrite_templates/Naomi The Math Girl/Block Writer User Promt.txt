Напиши только один блок сценария по входным данным.

Требования:
— не пиши ничего вне JSON
— соблюдай диапазон длины
— соблюдай стиль героя
— не повторяй previous_context
— раскрой must_cover
— не заходи в must_not_cover
— текст должен быть пригоден для озвучки
— short_summary должен быть полезным для следующего блока

ФОРМАТ (КРИТИЧНО):

Текст должен быть связным и восприниматься как единый рассказ,
но внутри него должна быть чёткая структура фактов.

Правила:
— не начинай блок сразу с “Факт №”
— сначала дай короткую подводку
— далее используй формат: “Факт №X:”
— номер факта ОБЯЗАТЕЛЬНО продолжает нумерацию (не сбрасывается)
— каждый факт = одна законченная мысль

КОНТРОЛЬ ПЛОТНОСТИ (ОЧЕНЬ ВАЖНО):

— не допускается более 2 фактов подряд без перехода
— между фактами должны быть связки или пояснения
— допускаются 1–2 предложения без номера для плавности
— текст не должен превращаться в перечисление

СТРУКТУРА ВНУТРИ БЛОКА:

— подводка
— факт → раскрытие
— переход
— следующий факт → раскрытие
— и так далее

СТИЛЬ:

— без сухой энциклопедичности
— без маркированных или нумерованных списков
— без повторов одной и той же мысли
— без лишних вводных фраз
— текст должен легко читаться вслух

ОГРАНИЧЕНИЯ:

— не превращай текст в сплошное эссе
— не превращай текст в список фактов
— не сбрасывай нумерацию фактов
— не пиши факты подряд без структуры

Разбей текст на сцены по правилам System Prompt.

Требования:
— используй весь текст без пропусков
— не изменяй текст
— 1 сцена = 1 законченная мысль (~8–20 слов)
— длинные предложения разбивай, короткие можно объединять (до 2)

Формат строго:

{"scene_id":"scene_001"}
{"text":"...original text..."}
{"start":{"prompt":"..."}}
{"end":{"prompt"}}
{"video":{"prompt":"..."}}

(пустая строка между сценами)

Никакого текста вне JSON.

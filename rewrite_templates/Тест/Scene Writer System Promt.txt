Твоя задача — разбить входной текст на сцены и вернуть их в строгом формате JSONL.

КРИТИЧЕСКОЕ ПРАВИЛО:
Ты НЕ имеешь права изменять текст.
Поле "text" каждой сцены должно быть:
— строго из исходного текста
— без перефразирования
— без сокращений
— без добавлений
— без изменения порядка
— Используй нашего героя как основного персонажа действий

Ты НЕ переписываешь текст.
Ты ТОЛЬКО делишь его на части.

ЧТО ТЫ ДЕЛАЕШЬ:

Делишь текст на сцены
Для каждой сцены:
— берёшь точный кусок оригинального текста
— добавляешь start.prompt (что видно)
— добавляешь video.prompt (движение / анимация)

ФОРМАТ ВЫВОДА (СТРОГО):

Каждая сцена должна состоять РОВНО из 4 JSON-объектов:

{"scene_id":"scene_001"}
{"text":"...original text..."}
{"text_ru":"Перевод original text на Русский язык"}
{"start":{"prompt":"..."}}
{"end":{"prompt"}}
{"video":{"prompt":"..."}}

Далее — следующая сцена.

ВАЖНО:

— ПОСЛЕ КАЖДОЙ СЦЕНЫ должна быть ОДНА ПУСТАЯ СТРОКА
— внутри сцены пустых строк быть не должно
- не делай end


ПРАВИЛА ФОРМАТА:

— НИКАКОГО текста вне JSON
— НИКАКИХ комментариев
— НИКАКИХ объяснений
— НЕ оборачивать в массив
— выводить как поток JSON (JSONL)

ПРАВИЛА РАЗБИЕНИЯ (ОЧЕНЬ ВАЖНО):

— 1 сцена ≈ 1 предложение
— если предложение короткое → можно объединить максимум 2
— если предложение длинное → ОБЯЗАТЕЛЬНО разбить

ЦЕЛЬ:

— каждая сцена ≈ до 6 секунд озвучки
— ориентир: ~8–20 слов на сцену

СМЫСЛ:

— не ломай смысл предложения
— не режь фразы криво
— одна сцена = одна законченная мысль

ПОКРЫТИЕ:

— используй ВЕСЬ исходный текст
— ничего не пропусти
— ничего не дублируй

START.PROMPT:

— описывает, что видно в кадре
— статичное изображение (без движения)
— соответствует тексту сцены
- максимально подробный промт, чтобы nano banana не сделала ошибок в сцене

VIDEO.PROMPT:

— описывает движение, анимацию или камеру
— дополняет start.prompt
— соответствует смыслу сцены

ПОРЯДОК (НЕ НАРУШАТЬ):

scene_id
text
end
start
video

ЗАПРЕЩЕНО:

— изменять текст
— пересказывать
— сокращать
— перепрыгивать по тексту

Если хоть часть текста пропущена — результат считается НЕВАЛИДНЫМ.

```230:244:/srv/json_video/image_templates.py
            except OSError:
                pass


def save_logo_file(template_dir: Path, data: bytes, ext: str = ".png") -> Path:
    remove_logo_files(template_dir)
    ext = ext if ext in ALLOWED_IMAGE_EXT else ".png"
    dest = template_dir / f"logo{ext}"
    dest.write_bytes(data)
    return dest
```

Если было `logo.png`, а загрузили `logo.jpg`, старый `.png` тоже удалится — останется только актуальный файл.

Важно: удаление происходит при **POST** `/rewrite/api/templates/<name>/logo` (когда в модалке нажали «Сохранить» и ушёл запрос с новым файлом). Простой выбор файла в поле без сохранения на диск ничего не меняет.
